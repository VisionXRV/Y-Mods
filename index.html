Minecraft 26.2 · Fabric

Y-Coordinate HUD

Zeigt deine aktuelle Blockhöhe dauerhaft oben rechts im HUD an — als kleine Zahl, ohne Einstellungen, rein client-seitig.

Installationsanleitung
Version 1.0.0 Größe 2,7 KB Einstellungen Keine Server Nicht nötig
Features

Was die Mod macht

Sechs Eigenschaften, die zählen.

Oben rechts, immer da

Die Blockhöhe (getBlockY) steht permanent als Zahl in der oberen rechten Ecke.

Ausblenden bei F3

Öffnest du den Debug-Bildschirm, verschwindet die Anzeige automatisch.

Reine Client-Mod

Kein Server nötig. Funktioniert auf jedem Server — auch ohne Mods.

Keine Konfiguration

Installieren, starten, fertig. Keine Config-Datei, keine Tasten.

Native Integration

Nutzt das HUD-System von Minecraft 26.2 — kein Overlay-Trick.

Sehr leichtgewichtig

Eine Java-Klasse, 2,7 KB, kein Netzwerk-Code.

Installation

In vier Schritten installiert

Keine Kommandozeile, kein Basteln.

1

Version herunterladen

Wähle deine Minecraft-Version und klicke auf Herunterladen. Die Datei wird über Google Drive heruntergeladen.

2

Auf Drive herunterladen

Auf der Drive-Seite klickst du oben links auf den Download-Button (Pfeil nach unten).

Download-Pfeil, oben links
3

In den Mods-Ordner legen

Die Datei ycoord-hud-1.0.0.jar in den Mods-Ordner kopieren:

%appdata%\.minecraft\mods
4

Minecraft starten

Mit dem Fabric-Profil starten. Die Y-Koordinate erscheint sofort.

Mod herunterladen

Wähle deine Minecraft-Version und lade die passende Mod herunter.
