Features

Was die Mod macht

Sechs Eigenschaften, die zählen.

Oben rechts, immer da

Die Blockhöhe (getBlockY) steht permanent als Zahl in der oberen rechten Ecke – mit 5 px Abstand zum Bildschirmrand.

Ausblenden bei F3

Öffnest du den Debug-Bildschirm, verschwindet die Anzeige automatisch. Sie stört nie den F3-Screen.

Reine Client-Mod

Kein Server nötig. Du kannst sie in Einzelspielen und auf jedem Server verwenden – auch auf Servern ohne Mods.

Keine Konfiguration

Keine Config-Datei, keine Tasten, keine Einstellungsseite. Installieren, starten, fertig.

Native Integration

Nutzt das HUD-System von Minecraft 26.2 (HudElementRegistry) – kein Overlay-Trick, kein Fremd-Code.

Sehr leichtgewichtig

Eine Java-Klasse, 2,7 KB, kein Netzwerk-Code. Messbar kein Einfluss auf die Framerate.

Technik

So funktioniert sie

Drei kleine Bausteine, keine Magie.

1

Registrierung

Beim Start registriert sich die Mod über die HudElementRegistry als HUD-Element des nativen Hud-Systems.

2

Wert lesen

Bei jedem Frame wird player.getBlockY() gelesen und in eine Zahl für den Bildschirmtext umgewandelt.

3

Zeichnen

Die Textbreite wird von der Bildschirmbreite abgezogen – so steht die Zahl immer oben rechts, 5 px vom Rand entfernt.
